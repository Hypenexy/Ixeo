Ixeo Metadata API

This endpoint fetches metadata for a URL and caches it for 24 hours.

Endpoint

GET /api/metadata?url=https://example.com

Example

curl "http://localhost:3000/api/metadata?url=https://example.com"

Response

{
  "url": "https://example.com",
  "title": "Example Domain",
  "description": "Example description",
  "image_url": null,
  "content_type": "text/html; charset=utf-8",
  "fetched_at": "2026-07-11T00:00:00Z",
  "expires_at": "2026-07-12T00:00:00Z"
}

Notes

  • The API validates that the URL is well formed.
  • Fresh results are reused from the database for 24 hours.
  • Expired entries are refreshed automatically on the next request.
